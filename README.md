# IELTS Essay Lab

A self-contained, mobile-friendly static web app based on the Bangla IELTS Writing Task 2 tutorial.

## Included
- Full 200-step tutorial, grouped into learning modules
- Search and module filtering
- Browser-based progress tracking with localStorage
- 61-card vocabulary/phrase deck with Bengali pronunciation and examples
- Sentence pattern laboratory
- 5-minute essay planning workspace
- 40-minute practice timer
- Practice essay pad with live word count
- 10 rotating practice prompts
- 15-question knowledge check
- Personal notes and exam checklist
- Light/dark mode
- No build step, no backend, no external dependency required

## Run
Open `index.html` in a modern browser.

## Deploy
Upload the whole folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static host.

## বাংলা সংস্করণ
এই সংস্করণে interface, ২০০টি lesson-এর teaching notes, vocabulary instructions, sentence-pattern explanations, planner hints, practice prompts, quiz ও exam checklist বাংলায় দেওয়া হয়েছে। IELTS-এর প্রয়োজনীয় English phrase ও example ইচ্ছাকৃতভাবে রাখা হয়েছে, এবং প্রতিটির সঙ্গে বাংলা ব্যাখ্যা/অর্থ যোগ করা হয়েছে।
